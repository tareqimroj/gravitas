## About the Game

Gravitas is a 2D space mini-golf game. The goal is to shoot the ball into a glowing hole in as few shots as possible, while planets and black holes bend its path with gravity. The background grid will bend around every planet, so the player can see the pull before shooting.

## How to Play (planned controls)

| Input | Action |
|---|---|
| Mouse drag (pull back from the ball) + release | Aim and shoot, like a slingshot |
| Right click while aiming | Cancel the shot |
| `Z` | Undo the last shot |
| `G` | Flip gravity for a moment |
| `P` | Pause / resume |
| `M` | Sound on / off |
| `R` | Restart the level |
| `Esc` | Back to menu |
| `Q` | Quit |

## Computer Graphics Concepts (planned)

- Game loop, 2D vectors and coordinate system
- Reflection formula for bouncing
- Radial gradients and additive blending (glow)
- Alpha blending and fading (trail, panels, particles)
- Mesh deformation by vertex displacement (spacetime grid)
- Parametric curves (planet orbits)
- Parallax layered rendering (starfield)
- Simple lighting on spheres
- Particle system and screen shake
- Interpolation and easing
